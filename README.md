# Projet PHP - Prise de rendez-vous

## Objectif
Créer un site Web simple en PHP permettant à des utilisateurs de prendre rendez-vous, et à un admin de les consulter.

## Installation
1. Importer le fichier `sql/base_rdv.sql` dans phpMyAdmin
2. Placer le dossier dans `htdocs` (XAMPP) ou `/var/www/html` (Linux)
3. Modifier `includes/db.php` si besoin

## Admin
- Login : `admin`
- Mot de passe : `admin`
